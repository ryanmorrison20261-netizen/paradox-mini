Run on a Mac (Apple silicon) with UTM: Create → Virtualize → Linux → import paradox-mini-arm64.qcow2 (UEFI). Or with QEMU:
zstd -d paradox-mini-arm64.qcow2.zst && qemu-system-aarch64 -M virt -accel hvf -cpu host -m 2048 -bios edk2-aarch64-code.fd -drive file=paradox-mini-arm64.qcow2,if=virtio,snapshot=on -nographic
x86_64 PC: qemu-system-x86_64 -m 2048 -bios OVMF.fd -drive file=paradox-mini-amd64.qcow2,if=virtio,snapshot=on -nographic
snapshot=on keeps the disk throwaway. Verify files with sha256sum -c SHA256SUMS. First login: user paradox, you set the password at a masked prompt.
