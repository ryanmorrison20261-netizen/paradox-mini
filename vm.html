← Paradox shell

This is a lightweight in-browser preview. It runs a tiny Linux (the v86 project's Buildroot test image, ~10 MB) in an x86 emulator inside this page, entirely offline after loading. It is not the full Paradox OS: the full OS image is in the Downloads list on the main page. Nothing is saved when you close this tab.
